# Car Price Prediction

A machine learning-based car price prediction application built with Python and Streamlit. The application uses a Random Forest Regression model to estimate vehicle prices based on features such as brand, model year, kilometers driven, fuel type, transmission, and engine size.

## Features

- Car price prediction using Machine Learning
- Random Forest Regression model
- Interactive Streamlit interface
- Vehicle configuration through user inputs
- Price estimation with suggested price range
- Price vs. mileage visualization
- Feature importance analysis
- Interactive Plotly charts

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly

## Machine Learning

The project generates a structured vehicle market dataset and performs data preprocessing and feature encoding before training a Random Forest Regression model.

The model uses vehicle characteristics such as:

- Brand
- Model
